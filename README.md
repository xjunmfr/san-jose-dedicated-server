## “优化”两个字值多少钱，得自己跑一遍

LightLayer 每个机房都给三档网络：优化对应大陆方向做了专门调度，标准是普通回国线路，国际是面向海外访问的国际带宽。三档的价格和带宽数值都不同。香港独服那档写的是 10M 优化 / 15M 全向 / 20M 国际，同一台机器换条线路，带宽差了一倍。

问题在于，配置页上写的线路名和路由实际走向经常对不上。2023 年 10 月一篇针对 RAKSmart 圣何塞独服的测评写得很直接：那台机器选的是“精品网络”，测去程时电信照样走 202.97，是普通 CN2，并非买家以为的 CN2 GIA。商家没有撒谎，它卖的确实叫精品网络，只是这个名字和你脑子里的 CN2 GIA 不是一回事。

判断方法只有一个：拿到测试 IP，或者用商家提供的 looking glass，从自己的网络环境跑 traceroute。电信看回程有没有经过 59.43 段，有才是 CN2 GIA；联通看是不是 9929；移动看是不是 CMIN2 或直连。美西 CN2 线路到国内电信的延迟普遍在 150–170ms，各家差距不大，真正的区别在晚高峰八点到十点会不会掉速丢包。

另外，“圣何塞”这个地名比字面意思大。有 IDC 服务商就把“圣何塞机房”的位置写成加州弗里蒙特市，两地隔了几十公里。需要跟客户交代服务器物理位置的话，下单前确认一下详细地址不亏。

## 配置怎么选：四种场景，四个答案

**单站、企业官网、日 PV 几千的博客**：E5-2660 / 16GB 直接够。这个配置的瓶颈不在内存和硬盘，在单核性能。E5-2660 是 2012 年的平台，单核性能和能效都落后于现在的主流服务器，跑 PHP 或 WordPress 并发一上来就顶不住。静态页或者靠缓存扛住大部分请求就没事；动态查询为主的话，问清楚有没有更新一代的 CPU。

**多站点、站群**：看 IPv4 数量，不看 CPU。圣何塞最多能给到 258 个 IPv4，可选 8 个 C 段，这是 LightLayer 在圣何塞比较特别的一项能力，做多站点的人会用到。这块要走询价。

**中转、代理、远程桌面**：选 200Mbps 国际不限流量那套。这类业务最怕月底流量表爆掉，不限流量意味着不用每天盯计数。200Mbps 对远程桌面和转发够用。

**大文件分发、视频、下载站**：反过来，选 1Gbps 端口 + 10TB 月流量。峰值带宽比流量总量重要，1Gbps 撑得住瞬时并发，10TB 够一个中等下载站跑一个月。真要更大，官方说单机最高 20Gbps，得单独谈。

## 第一年之后要花多少

促销价最容易骗人的地方是第二年。$57/月按年算 $684。如果续费翻倍到 $114/月，两年支出就是 $684 + $1368 = $2052。LightLayer 的促销机写明续费同价，两年 $684 × 2 = $1368，比翻倍的情况省下 $684，正好又是一年的钱。

这也是“续费同价”值得单独拎出来说的原因。它能算成一个具体数字。

拿同价位的东西做个参照。双十一那台 1 核 1GB 的圣何塞云服务器 $4.95/月，一年 $59.4，$684 能买 11 台多。但 11 台 1 核 1GB 拼不出 16GB 独享内存、整颗 CPU 和一块整盘。独服和云服务器的分界线不在价格，在资源会不会被邻居分走。

再加一个横向参照。RAKSmart 2023 年 10 月那版圣何塞独服价格表里，E3-1230 / 16GB / 1TB HDD 是 $96.15/月，E5-2650 / 32GB 是 $179/月，都配 1000M 端口和 10TB 流量。E3-1230 和 E5-2660 属于同一代硬件，LightLayer 的 $57 比它低了三成多。这个对比只说明 LightLayer 的定价在同代硬件里偏低，不代表 RAKSmart 现在还是那个价，那版价格距今已经三年。

## 这些情况别买

E5-2660 是十四年前的平台。要跑高并发数据库、实时计算、需要新指令集的负载，这台机器不合适，加钱换新平台更省事。

优化带宽只有 50Mbps，而且这是促销附赠的。业务主要面向国内用户的话，50Mbps 在访问高峰会不够，得加钱升。国际 200Mbps 是给海外用户的，两者不能互相替代。

独服不是即开即用。云服务器付完款几分钟开通，独服要走人工上架、装系统、配 IP 的流程，具体多久问客服，别按云服务器的时间预期安排上线。

## 下单前确认这五件事

1. 拿测试 IP 或 looking glass，从自己的宽带跑一遍 traceroute，电信确认 59.43 段，联通确认 9929。
2. 问清 10TB 流量是单向还是双向计费。两种口径行业里都有，有的商家明确写双向计算，上传下载都算，差出一倍。
3. 确认 IPv4 给几个、能不能加、加一个多少钱。站群需求提前说。
4. 确认续费价。促销机写着续费同价，非促销配置单独问。
5. 双十一的单子记得 1 小时内付款，超时自动取消，限量款卖完不补。
